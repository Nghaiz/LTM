\section{Biểu đồ và giao diện nội dung cá nhân thực hiện}
Phân hệ Master Server là \textbf{máy chủ TCP thuần .NET 8} --- không ASP.NET Core, không SignalR, không
WebSocket --- chỉ dùng \code{TcpListener} và \code{Socket}. Trọng tâm là bài toán \textbf{đóng khung thông điệp trên
luồng byte TCP}. Phạm vi còn gồm thư viện \code{IMasterClient} cho client Unity, liên kết game server -- master,
công cụ kiểm thử tải và hạ tầng triển khai (Docker, systemd, TLS, Terraform).
