A correction to the phase plan, recorded because it changed the work
---------------------------------------------------------------------
phase-6 § 6 describes Chat, LoadoutSelect and Ping as "ClientMessageTypes the server routes and
nobody writes". The server does NOT route them. `ServerMessageRouter.Route` has cases for Input,
AckBaseline, SpawnRequest, SeatRequest and VehicleInput; the other three fall to
`default: UnknownMessages++`. Adding client senders for them, as AC-6 literally asks, would have
shipped three write-only paths the server counts as corruption — strictly worse than the current
state. Scope was confirmed with the owner as gate-only, senders deferred.

Grading only the ROUTED set would then have dropped all three X-8 rows silently, so the
population is every declared enum member and an opcode nobody should write yet is a named
exemption. That choice is what surfaced X-30.
