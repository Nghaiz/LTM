WHAT THIS PROVES, AND WHAT IT DOES NOT.

Proves: the ack reaches the server and changes what the server sends. 1887 -> 1742 B/s per
client, -7.7%, with every other variable held. TryFindBaseline can only return true once an ack
has named a baseline, so a byte-count that moves at all is the encoder taking a different path
for the first time from this harness.

Does NOT prove: that -7.7% is the saving anyone should quote. It is two clients on an idle
Dustbowl over 30 seconds; the delta share depends entirely on how much of the world is moving,
and this configuration is close to the least favourable case for it. Phase 4 owns the real
bandwidth number (ledger rows B-16, B-17) and should re-measure under load rather than carry
this one forward. The point of this artifact is that the number Phase 4 measures will now
describe a real client's stream instead of an all-FULL one.

A NOTE ON THE FIRST ATTEMPT, WHICH FAILED FOR AN UNRELATED REASON.

The first paired run got 1/2 clients. The Editor's own NetClientBootstrap and harness client 0
both defaulted to IRONFRONT_CLIENT_PLAYER_ID = 1 (JoinTicketSource.Mint uses clientIndex + 1),
and the server enforces one session per player:

    [net] join ticket signed for player 1 as 'player'
    [net] join admitted for player 1
    [net] join rejected: AlreadyConnected
    [net] join admitted for player 2

That is a real defect surfaced by this run and filed separately -- the default collides with the
shipped harness's own numbering by construction, and lane B runs three rendered clients that
would all claim id 1. The runs above set IRONFRONT_CLIENT_PLAYER_ID=1000 for the Editor to get
a clean pair. Also visible in the same log, working as intended:

    [net] IRONFRONT_GAMESERVER_ACCEPT_UNSIGNED_TICKETS is set, but IRONFRONT_SHARED_SECRET is
          also set, so the flag is IGNORED and every join ticket must carry a valid signature.

BaselineAckPolicy is LINKED, not copied. 3C found SnapshotFlowIntegrationTests hand-rolling its
own ack beside the one a real client would send, so the delta path was graded against a second
