# the transport track — Phase 04 local implementation report

- **Date:** 2026-08-14
- **Scope:** complete the repository-side Phase 3/4 implementation without VPS, NAT, overnight
  soak or Unity Editor evidence
- **Status:** Code-complete for the available local scope; external acceptance evidence deferred

## Delivered

- `TransportDiagnosticsFormatter` centralizes the F3 fields and stable invariant-culture units in
  the engine-free transport assembly.
- `TransportDebugOverlay` is an optional Unity IMGUI component. It binds a real
  `ITransportClient`, refreshes at a bounded interval and uses `Shift+F3` so the legacy bare F3
  vehicle-seat binding is not changed.
- `Phase4ExperimentRunner` adds `--phase4-report` to the existing benchmark. It records
  deterministic local evidence for ACK history, per-channel head-of-line behavior and congestion
  hysteresis in a reviewable CSV.
- The Unity transport plugin is rebuilt from the current `netstandard2.1` transport assembly in
  the same change set as the source API/diagnostics changes.

## Local evidence

Generated artifact: [`2026-08-14-phase-04-local-experiments.csv`](2026-08-14-phase-04-local-experiments.csv)

The run uses one localhost connection, one second of idle traffic and the deterministic protocol
runner. The CSV shows:

| Area | Result |
|---|---|
| ACK history | Enabled history acknowledges the base ACK plus 32 prior packets; disabled history acknowledges only the base ACK |
| Head-of-line | Snapshot channel delivery is not blocked by a missing reliable-ordered packet |
| Congestion | RTT above the threshold enters BAD/10 Hz, observes the dwell timer, then recovers to GOOD |

The normal benchmark also reports the local pool comparison. It must be rerun on the target
machine for performance comparisons; the numbers are environment-dependent and are not promoted
to universal claims.
