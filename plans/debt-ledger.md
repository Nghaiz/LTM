## How to read a row

| Status | Meaning |
|---|---|
| `VERIFIED-OPEN` | Still open, confirmed by reading the tree. Ambiguity grades here, never to closed. |
| `RUN … ` | A run happened and did **not** close the row (FLAKY / BLOCKED / UNGRADEABLE / PARTIAL). Still open. |
| `DECIDED` / `WON'T-DO` | A decision, not work. Nothing is owed; the reopening condition is in the row. |
| `PARTIALLY CLOSED` | Half shipped, half owed. Counted in its own column. |

**A status cell records the run that produced it, not today's world.** When a row's named blocker
closes, the row does not update itself — that is the drift this ledger has been caught in three
